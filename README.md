# ItszuLib
Shared NeoForge framework for Itszuvalex's mods, written in Kotlin: block entities built from fragments, modules exposed as capabilities, item/energy storage, and block entity networks.

GitHub is the home of this repository; the full history from the former GitLab repo (https://gitlab.com/Itszuvalex-Minecraft/ItszuLib) is here.

- `main`: Minecraft 26.1.2 / NeoForge, written in Kotlin (the port, merged from `neoforge-26.1`). See `AGENTS.md` for building and the framework's concepts.
- `develop`, `develop-1.12.2*` and the older `develop-*` branches: the Minecraft 1.12.2 (Forge, Scala) line and older versions.
